I built an online exam system.

Here’s what makes it different:

📋 BULK IMPORT
Copy and paste questions from Word or Excel. Add 10, 20, or 50 questions in seconds—no need to type each one manually.

🛡️ ANTI-CHEAT
• Detects tab switching
• Blocks copy and paste during exams
• Disables right-click
• Detects screenshots (Print Screen, Snipping Tool)
• Displays student name and timestamp watermark on screen

⚠️ Any cheating attempt = 1 strike. 3 strikes = auto-submit.

🌙 DARK MODE
Switch between light and dark themes.

📊 ADMIN FEATURES
• Create timed exams
• Add questions manually or via bulk import
• View student results and scores

👨‍🎓 STUDENT FEATURES
• Take timed exams
• Live countdown timer
• Auto-submit when time expires
• Instant score results

Built using PHP, MySQL, and JavaScript.
